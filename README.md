#Aplikacja z przepisami

##Autorzy
Mateusz German
Maciej Adamczuk

##Opis projekt

Aplikacja webowa umożliwiająca przeglądanie przepisów kulinarnych pobieranych z API TheMealDB.


## Funkcjonalności

pobieranie danych z API
wyświetlanie listy przepisów
wyszukiwanie przepisów po nazwie
filtrowanie po kategorii
sortowanie A-Z i Z-A
dodawanie do ulubionych
usuwanie z ulubionych
zapisywanie ulubionych w localStorage
wyświetlanie szczegółów przepisu w oknie modalnym
responsywny interfejs

## Technologie

HTML
CSS
JavaScript
Fetch API
LocalStorage
